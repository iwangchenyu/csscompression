# CSS 格式化与在线压缩

> 在线格式化 CSS 代码使其易读，或压缩 CSS 减小体积、加快传输。

在线体验：https://wangchenyu.com/gongju/csscompression/

## 功能特性

- CSS 代码格式化（美化缩进）
- CSS 压缩（去除空格注释）
- 一键复制结果

## 使用方法

1. 用浏览器直接打开 `index.html`，无需安装任何软件、无需构建、无需后端服务。
2. 所有计算与处理均在浏览器本地完成，数据不会上传到服务器。
3. 处理完成后使用页面上的复制 / 导出按钮即可保存结果。

## 技术栈

原生 HTML / CSS / JavaScript

## 目录结构

```
├── index.html        # 主页面
├── assets/ 或本地资源 # 样式、脚本与静态资源（按需）
```
